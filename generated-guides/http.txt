Q: http 패키지가 뭐야?

A: 안녕! http 패키지는 Flutter나 Dart 앱에서 인터넷에 있는 데이터를 가져오거나 보낼 때 사용되는 아주 유용한 도구야. 마치 앱이 인터넷 서버와 대화할 수 있게 해주는 번역기 같은 거지! 웹사이트에서 정보를 가져오거나, 서버에 로그인 정보를 보내거나, 사진을 업로드하는 등 네트워크 통신이 필요한 대부분의 상황에서 사용돼.

난이도: 초급
예상 학습 시간: 5

Q: 설치는 어떻게 해?

A: 설치는 정말 간단해! 먼저 Flutter 프로젝트의 `pubspec.yaml` 파일에 `dependencies` 섹션 아래에 `http`를 추가해주면 돼.

dependencies:
  flutter:
    sdk: flutter

  http: ^1.2.1  # 최신 버전으로 입력해주면 좋아!

이렇게 추가한 후에 터미널에서 `flutter pub get` 명령어를 실행해주면 자동으로 다운로드되고 설치될 거야.

Q: http 패키지로 기본적인 HTTP 요청은 어떻게 보내?

A: 가장 기본적인 GET 요청을 보내는 방법을 알려줄게. 예를 들어, 특정 URL에서 정보를 가져오는 거지.

먼저, `dart:convert`와 `package:http/http.dart`를 임포트해야 해.

import 'dart:convert' as convert;
import 'package:http/http.dart' as http;

그리고 `async/await`를 사용해서 비동기적으로 요청을 보내고 응답을 기다리면 돼.

void main() async {
  var url = Uri.parse('https://example.com/data'); // 데이터를 가져올 URL
  var response = await http.get(url);

  if (response.statusCode == 200) { // 응답 코드가 200 (성공)이면
    print('응답 데이터: ${response.body}'); // 응답 본문을 출력
  } else {
    print('요청 실패: ${response.statusCode}');
  }
}

이 코드는 'https://example.com/data'에서 데이터를 가져와서 성공하면 내용을 출력하고, 실패하면 에러 코드를 출력하는 거야.

Q: http 패키지의 주요 기능은 뭐가 있어?

A: http 패키지는 정말 많은 기능을 제공하는데, 그중에서 꼭 알아두면 좋은 몇 가지를 소개할게!

1.  GET 요청: 웹에서 데이터를 가져올 때 가장 많이 사용돼. 위에서 본 것처럼 `http.get()` 함수를 사용해.
2.  POST 요청: 서버에 데이터를 보낼 때 사용해. 예를 들어 회원가입 정보나 게시글 내용을 보낼 때 `http.post()`를 써. 데이터를 보낼 때는 `body`에 보낼 내용을 담고, `headers`로 Content-Type 등을 지정해줘야 해.
3.  응답 처리: 서버에서 온 응답은 `Response` 객체로 받게 되는데, 이 객체로 응답 코드(statusCode), 응답 헤더(headers), 그리고 응답 본문(body)을 확인할 수 있어. JSON 데이터를 자주 사용하는데, `convert.jsonDecode()`를 써서 쉽게 Dart 객체로 변환할 수 있지.
4.  요청 헤더 설정: 특정 API를 사용하려면 인증 토큰 같은 헤더 정보를 보내야 할 때가 있어. `http.get()`이나 `http.post()` 함수에서 `headers` 매개변수를 사용해서 원하는 헤더를 추가할 수 있어.
5.  다양한 HTTP 메소드 지원: GET, POST 외에도 PUT, DELETE, PATCH 등 다양한 HTTP 메소드를 지원해서 서버와 복잡한 상호작용을 할 수 있어.

Q: http 패키지 사용하다 보면 어떤 에러가 자주 발생해?

A: 음, 네트워크 관련 작업이라 몇 가지 자주 마주치는 에러들이 있어.

1.  `ClientException` (또는 `SocketException`): 인터넷 연결이 안 되어 있거나, 서버 주소가 잘못되었거나, 서버가 응답하지 않을 때 발생하는 에러야. 인터넷 연결 상태를 확인하거나, URL이 정확한지 다시 한번 살펴보는 게 중요해.
2.  `FormatException`: 서버에서 받은 응답이 예상했던 JSON 형식이 아닐 때 발생할 수 있어. 서버에서 보내주는 데이터 형식을 정확히 확인하고, `convert.jsonDecode()`를 사용하기 전에 응답 본문이 유효한 JSON인지 검사하는 것이 좋아.
3.  `TimeoutException`: 서버 응답이 너무 오래 걸릴 때 발생해. 네트워크 상태가 좋지 않거나 서버 부하가 심할 때 나타날 수 있는데, 보통은 네트워크 환경을 개선하거나 서버 측 문제를 해결해야 하지만, 클라이언트 측에서는 요청에 타임아웃 설정을 추가해서 무한정 기다리는 것을 방지할 수도 있어.

Q: http 패키지를 실무에서 더 잘 활용하려면 어떤 팁들이 있을까?

A: 그래, 몇 가지 실무 팁을 알려줄게!

1.  에러 핸들링을 꼼꼼하게 하자: 네트워크 요청은 실패할 확률이 항상 있어. `try-catch` 문을 사용해서 `ClientException`이나 `FormatException` 같은 예외를 잘 잡아내고, 사용자에게 친절하게 에러 메시지를 보여주거나 재시도 기능을 제공하는 게 좋아.
2.  응답 캐싱을 고려해보자: 매번 똑같은 데이터를 서버에서 가져오는 것은 비효율적일 수 있어. 자주 변경되지 않는 데이터라면, 한번 가져온 데이터를 앱 내에 저장해두고(캐싱) 다음에 요청할 때는 캐시된 데이터를 보여주는 방식으로 성능을 개선할 수 있어.
3.  비동기 처리를 잘 활용하자: `http` 패키지는 기본적으로 비동기 API를 제공해. `async/await` 패턴을 잘 사용해서 UI가 멈추지 않고 네트워크 요청을 처리하는 것이 중요해. 예를 들어, 데이터를 가져오는 동안 로딩 스피너를 보여주는 식으로 사용자 경험을 좋게 만들 수 있지.
4.  `http.Client`를 재사용하자: 여러 개의 요청을 보내야 할 때, 매번 `http.get()`이나 `http.post()`를 호출하는 대신 `http.Client()`를 생성해서 재사용하면 연결을 효율적으로 관리할 수 있어. 특히 같은 호스트로 여러 요청을 보낼 때 유용해.

Q: POST 요청으로 데이터를 보내는 예제를 보여줄 수 있을까?

A: 물론이지! POST 요청은 주로 서버에 새로운 데이터를 생성하거나 업데이트할 때 사용해. 예를 들어, 사용자가 입력한 회원 가입 정보를 서버로 보내는 경우를 생각해보자.

먼저, 보낼 데이터를 Dart Map 형태로 준비하고, `dart:convert`를 사용해서 JSON 문자열로 변환해야 해.

import 'dart:convert' as convert;
import 'package:http/http.dart' as http;

void main() async {
  var url = Uri.parse('https://example.com/users'); // 사용자 정보를 보낼 URL

  var newUser = {
    'name': '홍길동',
    'email': 'hong@example.com',
    'password': 'mypassword',
  };

  // JSON 형식으로 인코딩
  var body = convert.jsonEncode(newUser);

  try {
    var response = await http.post(
      url,
      headers: {
        'Content-Type': 'application/json; charset=UTF-8', // 보내는 데이터 형식을 명시
      },
      body: body,
    );

    if (response.statusCode == 201) { // 201은 리소스 생성 성공을 의미하는 경우가 많아
      print('사용자 생성 성공!');
      print('응답: ${response.body}');
    } else {
      print('사용자 생성 실패. 상태 코드: ${response.statusCode}');
      print('에러 메시지: ${response.body}');
    }
  } catch (e) {
    print('요청 중 에러 발생: $e');
  }
}

이 예제에서는 `Content-Type` 헤더를 `application/json`으로 설정해서 서버가 JSON 데이터를 받을 준비가 되었음을 알리고 있어.

Q: PUT 요청은 언제 사용하고 어떻게 보내?

A: PUT 요청은 주로 서버에 있는 기존 리소스 전체를 새로운 내용으로 교체하거나 생성할 때 사용돼. 마치 파일 내용을 완전히 덮어쓰는 것과 비슷하다고 생각하면 돼.

예를 들어, 사용자의 프로필 정보를 업데이트할 때 PUT 요청을 사용할 수 있어.

import 'dart:convert' as convert;
import 'package:http/http.dart' as http;

void main() async {
  var userId = '123'; // 업데이트할 사용자의 ID
  var url = Uri.parse('https://example.com/users/$userId'); // 해당 사용자의 URL

  var updatedUserInfo = {
    'name': '홍길동 수정',
    'email': 'hong.updated@example.com',
    'age': 30,
  };

  var body = convert.jsonEncode(updatedUserInfo);

  try {
    var response = await http.put(
      url,
      headers: {
        'Content-Type': 'application/json; charset=UTF-8',
      },
      body: body,
    );

    if (response.statusCode == 200) { // 200은 성공적인 응답을 의미해
      print('사용자 정보 업데이트 성공!');
      print('응답: ${response.body}');
    } else {
      print('사용자 정보 업데이트 실패. 상태 코드: ${response.statusCode}');
      print('에러 메시지: ${response.body}');
    }
  } catch (e) {
    print('요청 중 에러 발생: $e');
  }
}

POST와 비슷하게 `http.put()` 함수를 사용하고, `headers`와 `body`를 설정해주는 방식이야. PUT 요청은 보통 요청 본문이 리소스의 전체 표현이어야 한다는 특징이 있어.

Q: DELETE 요청은 어떻게 보내는 거야?

A: DELETE 요청은 서버에 있는 특정 리소스를 삭제할 때 사용해.

예를 들어, 특정 사용자를 시스템에서 완전히 삭제하고 싶을 때 DELETE 요청을 보내는 거지.

import 'package:http/http.dart' as http;

void main() async {
  var userId = '456'; // 삭제할 사용자의 ID
  var url = Uri.parse('https://example.com/users/$userId'); // 해당 사용자의 URL

  try {
    var response = await http.delete(url);

    if (response.statusCode == 200) { // 200 또는 204 (No Content)가 성공을 의미할 수 있어
      print('사용자 삭제 성공!');
    } else {
      print('사용자 삭제 실패. 상태 코드: ${response.statusCode}');
      print('응답: ${response.body}');
    }
  } catch (e) {
    print('요청 중 에러 발생: $e');
  }
}

DELETE 요청은 보통 요청 본문이 필요하지 않아. 단순히 삭제할 리소스의 URL만 지정해주면 돼. 응답 코드 200 (OK) 또는 204 (No Content)가 성공적으로 삭제되었음을 나타낼 수 있어.

Q: http 패키지에서 JSON 데이터를 파싱할 때 주의할 점이 있을까?

A: 응, JSON 데이터 파싱은 네트워크 통신에서 정말 중요하니까 몇 가지 주의할 점이 있어.

1.  응답 데이터 타입 확인: 서버에서 보내주는 데이터가 항상 JSON일 거라고 단정하면 안 돼. 가끔 HTML이나 일반 텍스트를 받을 수도 있거든. `response.headers['content-type']`를 확인해서 `application/json`인지 먼저 체크하고 `convert.jsonDecode()`를 사용하는 것이 안전해.
2.  `null` 값 처리: JSON 데이터 안에는 `null` 값이 포함될 수 있어. Dart에서는 `null`을 다룰 때 `?` 연산자나 `??` 연산자를 사용해서 안전하게 처리해야 해. 예를 들어, `jsonDecode(response.body)['age']` 처럼 바로 접근하면 `null`일 때 에러가 날 수 있으니, `(jsonDecode(response.body)['age'] as int?) ?? 0` 와 같이 처리하는 것이 좋아.
3.  JSON 구조 변경 대비: API 서버가 업데이트되면서 JSON 구조가 변경될 수 있어. 이런 경우 앱에서 JSON을 파싱하는 부분이 에러를 뿜어낼 수 있지. 이런 상황에 대비해서 JSON 파싱 로직을 별도의 함수로 분리하거나, `json_serializable` 같은 패키지를 사용해서 코드 생성으로 관리하면 유지보수하기가 훨씬 수월해져.
4.  인코딩 문제: 한글과 같은 유니코드 문자가 깨져서 오는 경우가 종종 있어. `convert.jsonDecode()`는 UTF-8을 기본으로 처리하지만, 서버 설정이나 다른 이유로 문제가 발생할 수 있어. 이럴 때는 `utf8.decode(response.bodyBytes)` 와 같이 바이트를 직접 디코딩하는 방법을 고려해볼 수도 있어.

Q: http 패키지와 Dio 패키지의 차이점은 뭐야?

A: 좋은 질문이야! http 패키지와 Dio 패키지 모두 Flutter/Dart에서 네트워크 통신을 할 때 많이 사용되는데, 몇 가지 차이점이 있어.

http 패키지는 Dart 표준 라이브러리에 더 가깝고, 매우 가볍고 단순한 API를 제공해. 기본적인 GET, POST, PUT, DELETE 요청을 보내는 데는 아주 훌륭하고, 의존성이 적다는 장점이 있어.

반면에 Dio는 더 많은 기능을 제공하는 고성능 HTTP 클라이언트 라이브러리야.

*   요청/응답 인터셉터: 요청을 보내기 전이나 응답을 받은 후에 공통적으로 처리해야 할 로직(예: 토큰 자동 추가, 에러 로깅)을 쉽게 구현할 수 있어.
*   폼 데이터 지원: 파일 업로드나 복잡한 폼 데이터 전송을 더 쉽게 할 수 있도록 도와줘.
*   요청 취소: 진행 중인 네트워크 요청을 취소하는 기능을 제공해서 불필요한 네트워크 부하를 줄일 수 있어.
*   타임아웃 설정: 요청별로 타임아웃을 더 세밀하게 설정할 수 있어.
*   전역 설정: 기본 URL, 헤더 등을 미리 설정해두고 재사용할 수 있어.

간단한 API 연동에는 http 패키지가 충분하지만, 복잡한 네트워크 로직이나 파일 업로드, 인터셉터 기능이 필요하다면 Dio 패키지가 더 좋은 선택이 될 수 있어.

Q: http 패키지를 사용할 때 URL을 어떻게 다루는 게 좋아?

A: URL을 다룰 때는 `Uri` 클래스를 사용하는 것이 훨씬 안전하고 편리해. `Uri.parse()`나 `Uri.https()` 같은 함수를 사용하면 URL을 파싱해서 각 부분을 쉽게 접근하고 조작할 수 있거든.

예를 들어, `Uri.https()`를 사용하면 HTTPS 프로토콜을 명시하고, 호스트, 경로, 쿼리 매개변수를 쉽게 구성할 수 있어.

import 'package:http/http.dart' as http;

void main() async {
  // Google Books API 예제
  var url = Uri.https(
    'www.googleapis.com', // 호스트
    '/books/v1/volumes', // 경로
    {'q': '{http}', 'maxResults': '10'}, // 쿼리 매개변수
  );

  var response = await http.get(url);

  if (response.statusCode == 200) {
    print('성공적으로 데이터를 가져왔습니다.');
    // ... (응답 처리 로직)
  } else {
    print('요청 실패: ${response.statusCode}');
  }
}

이렇게 `Uri` 객체를 사용하면 URL을 문자열로 직접 다룰 때 발생할 수 있는 인코딩 문제나 잘못된 형식의 URL 사용을 방지할 수 있어. 특히 쿼리 매개변수가 많을 때는 `Uri.https()`를 사용하는 것이 훨씬 가독성이 좋고 편리해.

Q: http 패키지로 파일을 업로드하려면 어떻게 해야 해?

A: 파일을 업로드하는 것은 조금 더 복잡할 수 있는데, `http` 패키지로도 가능해. 보통 `MultipartFile`을 사용해서 여러 부분으로 나뉜 데이터를 보낼 때 쓰는데, `http` 패키지 자체에는 `MultipartFile`을 직접 지원하는 함수가 없어서 조금 우회해야 해.

하지만 `http` 패키지를 사용해서 파일을 업로드하는 일반적인 방법은 다음과 같아.

1.  `MultipartRequest` 사용: `http` 패키지는 `MultipartRequest`라는 클래스를 제공하는데, 이걸 사용하면 여러 파트로 나뉜 요청을 만들 수 있어.
2.  파일 읽기: 업로드할 파일을 `File` 객체로 읽어와야 해.
3.  `bytes`와 `filename` 설정: `MultipartFile`을 만들 때 파일의 내용을 `bytes`로, 파일 이름을 `filename`으로 설정해줘야 해.

아래는 예시 코드야. `path_provider`나 `file_picker` 같은 패키지를 사용해서 실제 파일 객체를 가져와야 할 수도 있어.

import 'dart:convert' as convert;
import 'dart:io' as io; // dart:io를 임포트해야 File을 사용할 수 있어
import 'package:http/http.dart' as http;

Future<void> uploadFile(io.File file) async {
  var url = Uri.parse('https://example.com/upload'); // 파일 업로드 URL

  var request = http.MultipartRequest('POST', url);

  // 파일 스트림을 읽어서 MultipartFile로 변환
  var stream = http.ByteStream(file.openRead());
  var length = await file.length();

  var multipartFile = http.MultipartFile(
    'file', // 서버에서 기대하는 파일 필드 이름
    stream,
    length,
    filename: file.uri.pathSegments.last, // 파일 이름
  );

  request.files.add(multipartFile);

  // 필요하다면 다른 폼 데이터도 추가할 수 있어
  request.fields['userId'] = 'user123';

  try {
    var response = await request.send(); // 요청 보내기

    if (response.statusCode == 200) {
      print('파일 업로드 성공!');
      // 응답 본문을 읽어서 처리
      var responseBody = await response.stream.bytesToString();
      print('응답: $responseBody');
    } else {
      print('파일 업로드 실패. 상태 코드: ${response.statusCode}');
      var responseBody = await response.stream.bytesToString();
      print('에러 메시지: $responseBody');
    }
  } catch (e) {
    print('요청 중 에러 발생: $e');
  }
}

이 코드는 `request.send()` 메소드를 사용해서 요청을 보내고, 응답을 스트림으로 받아 처리하는 방식이야. 서버에서 어떤 이름으로 파일을 받을지(`'file'` 부분)를 정확히 알아야 해.

Q: http 패키지에서 응답을 받았는데 JSON이 아닌 다른 형식일 때 어떻게 처리해야 할까?

A: 좋은 질문이야! 서버에서 항상 JSON만 보내리라는 보장은 없거든. 응답이 JSON이 아닐 때를 대비해서 몇 가지 방법으로 처리할 수 있어.

1.  `Content-Type` 헤더 확인: 가장 먼저 `response.headers['content-type']`를 확인해서 `'application/json'`으로 시작하는지 보는 거야. 만약 이게 아니라면 JSON 디코딩을 시도하기 전에 다른 처리를 해야 할 수 있어.
2.  `response.body`를 문자열로 처리: 만약 응답이 JSON이 아니라 일반 텍스트라면, `response.body`는 이미 문자열이기 때문에 그대로 사용하면 돼. 예를 들어, 서버에서 HTML을 반환한다면 `response.body`에 HTML 내용이 담겨 있을 거야.
3.  `response.bodyBytes` 사용: 때로는 응답이 바이너리 데이터(예: 이미지, PDF)일 수 있어. 이럴 때는 `response.body` 대신 `response.bodyBytes`를 사용해서 바이트 배열로 받고, 필요에 따라 파일로 저장하거나 처리할 수 있어.
4.  `try-catch`로 안전하게 디코딩: `convert.jsonDecode()`를 호출하기 전에 `try-catch` 블록으로 감싸서, 만약 JSON 디코딩에 실패하면 에러를 잡아서 다른 방식으로 처리하는 것도 좋은 방법이야.

예시:

import 'dart:convert' as convert;
import 'package:http/http.dart' as http;

void main() async {
  var url = Uri.parse('https://example.com/resource');
  var response = await http.get(url);

  if (response.statusCode == 200) {
    var contentType = response.headers['content-type'];

    if (contentType != null && contentType.contains('application/json')) {
      // JSON 형식일 경우
      try {
        var jsonData = convert.jsonDecode(response.body);
        print('JSON 데이터: $jsonData');
      } catch (e) {
        print('JSON 디코딩 오류: $e');
        print('응답 본문: ${response.body}');
      }
    } else if (contentType != null && contentType.contains('text/html')) {
      // HTML 형식일 경우
      print('HTML 응답: ${response.body}');
      // HTML 파싱을 위한 라이브러리 (예: html)를 사용할 수도 있어
    } else {
      // 그 외의 경우 (바이너리 데이터 등)
      print('알 수 없는 응답 형식.');
      print('응답 본문 (바이트): ${response.bodyBytes}');
    }
  } else {
    print('요청 실패: ${response.statusCode}');
  }
}

이렇게 응답의 `Content-Type`을 확인하고, `try-catch`를 활용하면 다양한 형식의 응답을 안전하게 처리할 수 있어.

Q: http 패키지에서 커스텀 헤더를 추가하는 방법을 다시 한번 알려줘.

A: 물론이지! 커스텀 헤더를 추가하는 건 특정 API를 사용하거나, 서버에 특정 정보를 전달해야 할 때 아주 중요해. `http` 패키지에서 GET, POST 등 대부분의 HTTP 요청 함수는 `headers`라는 매개변수를 받고 있어. 이 `headers` 매개변수는 `Map<String, String>` 타입이야.

간단하게 `Map` 형태로 원하는 헤더 이름과 값을 넣어서 전달해주면 돼.

예시:

import 'package:http/http.dart' as http;

void main() async {
  var url = Uri.parse('https://api.example.com/data');

  var response = await http.get(
    url,
    headers: {
      'Authorization': 'Bearer YOUR_ACCESS_TOKEN', // 인증 토큰
      'X-Custom-Header': 'MyValue', // 나만의 커스텀 헤더
      'Accept': 'application/json', // 서버에 JSON 응답을 원한다고 알림
    },
  );

  if (response.statusCode == 200) {
    print('요청 성공!');
  } else {
    print('요청 실패: ${response.statusCode}');
  }
}

위 예시처럼 `Authorization` 헤더에 접근 토큰을 넣거나, `X-Custom-Header`처럼 임의의 헤더를 추가할 수 있어. `Accept` 헤더는 서버에게 클라이언트가 어떤 종류의 응답을 원하는지 알려주는 역할을 하기도 해.

POST 요청에서도 마찬가지로 `http.post()` 함수에 `headers` 매개변수를 추가해주면 돼.

Q: http 패키지로 요청을 보낼 때 타임아웃을 설정할 수 있어?

A: 네, `http` 패키지 자체에는 직접적인 타임아웃 설정 기능이 내장되어 있지 않아요. 하지만 `dart:async`의 `Future.timeout()` 메서드를 사용하면 간편하게 타임아웃을 구현할 수 있어요.

방법은 다음과 같습니다.

1.  `http` 요청을 `Future`로 받습니다.
2.  이 `Future`에 `.timeout()` 메서드를 적용합니다.
3.  `onTimeout` 콜백에서 타임아웃 시 실행될 로직을 정의합니다.

예시 코드를 보여드릴게요.

import 'dart:async';
import 'package:http/http.dart' as http;

void main() async {
  var url = Uri.parse('https://slow.example.com/data'); // 응답이 느린 URL이라고 가정
  Duration timeoutDuration = Duration(seconds: 5); // 5초 동안 응답이 없으면 타임아웃

  try {
    var response = await http.get(url).timeout(
      timeoutDuration,
      onTimeout: () {
        // 타임아웃 시 실행될 로직
        print('요청이 시간 초과되었습니다.');
        // 타임아웃 시 null이나 특정 값을 반환할 수 있어요.
        // 여기서는 null을 반환하도록 할게요.
        return http.Response('Timeout', 408); // 408 Request Timeout 상태 코드
      },
    );

    if (response.statusCode == 200) {
      print('요청 성공!');
      print('응답: ${response.body}');
    } else if (response.statusCode == 408) {
      print('타임아웃 에러가 발생했습니다.');
    } else {
      print('요청 실패. 상태 코드: ${response.statusCode}');
    }
  } catch (e) {
    // SocketException 등 다른 네트워크 에러 처리
    print('네트워크 오류 발생: $e');
  }
}

이런 식으로 `Future.timeout()`을 사용하면 네트워크 요청이 너무 오래 걸리는 것을 방지하고, 사용자에게 더 나은 경험을 제공할 수 있어요. `onTimeout` 콜백 안에서 `http.Response` 객체를 직접 생성해서 반환할 수도 있고, 단순히 에러 메시지만 출력하고 `null`을 반환할 수도 있습니다.

Q: http 패키지로 GET 요청을 보낼 때, URL에 포함되는 쿼리 파라미터를 어떻게 넘겨야 해?

A: URL에 포함되는 쿼리 파라미터는 `Uri` 객체를 사용할 때 아주 쉽게 관리할 수 있어. `Uri.https()`나 `Uri.http()` 함수를 사용할 때 세 번째 인자로 맵(Map) 형태의 쿼리 파라미터를 전달하면 돼.

이 맵의 키(key)는 파라미터 이름이 되고, 값(value)은 해당 파라미터의 값이 되지. `Uri` 객체가 자동으로 URL 인코딩을 처리해주기 때문에 안전하게 사용할 수 있어.

예시를 보여줄게.

import 'package:http/http.dart' as http;

void main() async {
  // Google Books API 예제에서 'q'와 'maxResults' 쿼리 파라미터를 설정
  var url = Uri.https(
    'www.googleapis.com',
    '/books/v1/volumes',
    {
      'q': '{http}', // 검색어
      'maxResults': '10', // 최대 결과 수
      'printType': 'books', // 검색할 출력 타입
    },
  );

  print('요청할 URL: $url'); // 생성된 URL 확인

  var response = await http.get(url);

  if (response.statusCode == 200) {
    print('요청 성공!');
    // print('응답: ${response.body}'); // 실제 응답 내용 출력
  } else {
    print('요청 실패. 상태 코드: ${response.statusCode}');
  }
}

이렇게 `Uri.https()`의 세 번째 인자로 맵을 전달하면, `http.get()` 함수는 자동으로 이 맵을 이용해 올바른 형식의 URL을 만들어 요청을 보내게 돼. 쿼리 파라미터가 많아져도 코드가 깔끔하게 유지되는 장점이 있어.

Q: http 패키지 사용 시 `dart:io`를 임포트해야 하는 경우가 있어?

A: 네, `http` 패키지 자체는 `dart:io`를 직접적으로 요구하지는 않지만, 특정 기능을 사용하거나 더 복잡한 네트워크 작업을 할 때 `dart:io`의 일부 클래스들을 사용해야 하는 경우가 있어.

주요하게 `dart:io`를 임포트하게 되는 경우는 다음과 같아.

1.  파일 업로드: 파일을 업로드할 때, 해당 파일을 나타내는 `io.File` 객체를 다루기 위해 `dart:io`를 임포트해야 해. 위에서 보여줬던 파일 업로드 예제에서도 `import 'dart:io' as io;`를 사용했지.
2.  소켓 관련 정보 접근: 때로는 네트워크 연결의 소켓(socket)에 대한 더 상세한 정보에 접근해야 할 때가 있는데, 이럴 때 `dart:io`가 관련 클래스들을 제공해.
3.  특정 플랫폼 기능: Flutter는 크로스 플랫폼을 지원하지만, 가끔 플랫폼별로 다른 방식으로 네트워크를 처리해야 할 때 `dart:io`의 일부 기능이 필요할 수 있어.

하지만 대부분의 기본적인 HTTP 요청(GET, POST 등)은 `http` 패키지만으로도 충분히 가능하며, `dart:io`를 명시적으로 임포트하지 않아도 돼. 파일 업로드처럼 특수한 경우가 아니라면, `http` 패키지만 사용하는 것이 더 깔끔할 수 있어.

Q: http 패키지로 요청을 보낼 때, 응답이 성공적이지 않았을 때(예: 404 Not Found, 500 Internal Server Error) 어떻게 에러 처리를 하는 게 좋아?

A: 좋은 질문이야! 네트워크 요청은 언제나 실패할 가능성이 있으니, 성공적이지 않은 응답에 대한 에러 처리는 정말 중요해. `http` 패키지에서는 응답 객체의 `statusCode`를 확인해서 성공/실패를 구분하고, 그에 따라 적절한 처리를 해줘야 해.

일반적으로 다음과 같은 방법으로 에러 처리를 할 수 있어.

1.  `statusCode` 확인: 응답 객체(`response`)의 `statusCode` 속성을 확인해.
    *   2xx (예: 200 OK, 201 Created): 성공적인 요청을 의미해.
    *   3xx (예: 301 Moved Permanently): 리다이렉션. `http` 패키지는 기본적으로 리다이렉션을 자동으로 따라가지만, 설정을 통해 막을 수도 있어.
    *   4xx (예: 400 Bad Request, 401 Unauthorized, 404 Not Found): 클라이언트 측의 문제.
    *   5xx (예: 500 Internal Server Error, 503 Service Unavailable): 서버 측의 문제.

2.  `try-catch` 블록 활용: 네트워크 연결 자체가 실패하는 경우(인터넷 연결 끊김, DNS 오류 등)에는 `http.get()` 같은 함수 호출 시 예외(Exception)가 발생해. 이런 예외들은 `try-catch` 블록으로 잡아내야 해. `ClientException`이나 `SocketException` 등이 대표적이야.

3.  `response.body`로 에러 메시지 확인: 4xx나 5xx 에러가 발생했을 때, 서버는 종종 에러에 대한 상세 정보를 JSON이나 텍스트 형태로 `response.body`에 담아 보내. 이 내용을 파싱해서 사용자에게 보여주거나 로깅하는 것이 좋아.

예시 코드를 볼까?

import 'dart:convert' as convert;
import 'package:http/http.dart' as http;

void main() async {
  var url = Uri.parse('https://example.com/nonexistent-page'); // 존재하지 않는 페이지라고 가정

  try {
    var response = await http.get(url);

    if (response.statusCode == 200) {
      print('요청 성공!');
      var jsonResponse = convert.jsonDecode(response.body);
      print('응답 데이터: $jsonResponse');
    } else {
      // 2xx 외의 모든 상태 코드를 에러로 간주
      print('요청 실패!');
      print('상태 코드: ${response.statusCode}');

      // 서버에서 에러 메시지를 보냈다면 파싱해서 출력
      try {
        var errorBody = convert.jsonDecode(response.body);
        print('에러 상세: ${errorBody}');
      } catch (e) {
        // JSON 디코딩 실패 시 일반 텍스트로 출력
        print('에러 메시지 (텍스트): ${response.body}');
      }
    }
  } catch (e) {
    // 네트워크 연결 자체의 오류 처리
    print('네트워크 오류 발생: $e');
    if (e is http.ClientException) {
      print('클라이언트 오류: ${e.message}');
    }
  }
}

이렇게 `statusCode`를 확인하고, `try-catch`를 함께 사용하면 네트워크 요청의 다양한 실패 상황에 대해 좀 더 견고하게 대처할 수 있어.
